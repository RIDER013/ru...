# RIDER (Web)

**VOICE CONTROL • BLUETOOTH**

RIDER is a hands-free voice control and Bluetooth companion application designed for riders and drivers. It enables hands-free swipe-up gestures via voice recognition or Bluetooth controls while riding.

## Features

- **Voice Command Recognition**: Trigger swipe gestures by saying *"Rider swipe up"*.
- **Gesture Control**: Replicates the 350ms upward accessibility swipe gesture (`startY: 82%` to `endY: 25%`) to scroll feeds, media, reels, or navigation cards hands-free.
- **Accessibility Control Settings**: Configurable service state, permissions, and gesture parameters.
- **Bluetooth Companion**: Pair, scan, and monitor paired Bluetooth earbuds, helmet intercoms (e.g. Cardo, Sena), and headsets.
- **Interactive Gesture Canvas**: Visual feedback and test surface for dispatching swipe gestures.

## Getting Started

```bash
npm install
npm run dev
```

Built with React 18, Vite, TypeScript, and Tailwind CSS.
